# 界面设计决策

## 已定事项

| 项 | 决定 | 定于 |
| --- | --- | --- |
| 视觉方向 | **Fluent 原生**（方案 A：浅灰底 + 白卡片 + 圆角，靠明度分层） | 2026-09-25 |
| 手势绑定表排布 | **紧凑表格**（一行一条，20px 折线轨迹图标 + 触发键徽章 + 命令 + 参数） | 2026-09-25 |

## 设计基准

`docs/prototypes/settings.html` —— 可交互原型，六页可切换（窗口操作 / 鼠标手势 / 触发与反馈 / 应用规则 / 通用 / 关于）。
手势页顶部保留了三种排布的切换开关，便于日后回溯比较。

**实现时以该原型为准，逐像素比对。** 原型是纯 HTML/CSS/JS 自包含，无外链。

## 信息架构

| 页 | 内容 |
| --- | --- |
| 窗口操作 | Alt + 各鼠标键的动作分配、拖拽行为参数、修饰键说明 |
| 鼠标手势 | 手势绑定表（紧凑表格）、触发键/修饰键/命令/参数 |
| 触发与反馈 | 四色轨迹配色、显示开关、触发判定（起始超时/8方向/步数）、屏幕边缘 |
| 应用规则 | 按进程覆盖与禁用、全局黑名单 |
| 通用 | 启动、托盘、暂停热键、语言、更新、多实例 |
| 关于 | 版本、许可证、项目主页、来源致谢 |

## 视觉 token

```
背景/导航    #F4F4F4      导航选中  #E4E7EB
内容面板     #FCFCFC      卡片      #FFFFFF
标题栏       #F0F0F0      分隔线    #E3E3E3 ~ #EFEFEF
正文         #2C2C2C      次级文字  #6B6B6B      弱化  #999999
圆角         6px（控件） / 8-10px（卡片、窗口）
字号         页标题 23px / 正文 14px / 分组标题 12.5px / 徽章 11.5px
```

触发键徽章配色（手势表）：

| 触发键 | 底色 | 文字 |
| --- | --- | --- |
| 右键 | `#E8EEF7` | `#3A6EA5` |
| 中键 | `#EFEAE4` | `#8A6A45` |
| 侧键 | `#EDE8F0` | `#6B4A7A` |

## 硬性约束

- 禁止 emoji，图标一律内联 SVG 线性风格（stroke 1.6，round cap）
- 黑白灰基底，点缀色仅在明确要求时使用
- 界面文案为简体中文
- 字号偏大，不做小字排版（林哥反馈过字体太小要凑近看）

## 实施

Phase 3 用 **Avalonia**（net8.0）实现。选它而非 WPF 的原因：可在 Linux 构建验证、支持 NativeAOT、未来可跨平台。
