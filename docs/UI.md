# 界面设计决策

## 已定事项

| 项 | 决定 | 定于 |
| --- | --- | --- |
| 视觉方向 | **Fluent 原生**（方案 A：浅灰底 + 白卡片 + 圆角，靠明度分层） | 2026-09-25 |
| 手势绑定表排布 | **紧凑表格**（一行一条，20px 折线轨迹图标 + 触发键徽章 + 命令 + 参数） | 2026-09-25 |

## 设计基准

`docs/prototypes/settings.html` —— 可交互原型，六页可切换（窗口操作 / 鼠标手势 / 触发与反馈 / 应用规则 / 通用 / 关于）。
手势页顶部保留了三种排布的切换开关，便于日后回溯比较。

**实现时以该原型为准，逐像素比对。** 原型是纯 HTML/CSS/JS 自包含，无外链。

## 硬性约束

- 禁止 emoji，图标一律内联 SVG 线性风格（stroke 1.6，round cap）
- 黑白灰基底，点缀色仅在明确要求时使用
- 界面文案为简体中文
- 字号偏大，不做小字排版（林哥反馈过字体太小要凑近看）

## 导航图标（2026-09-26 定稿）

六个导航图标的语义与几何（`viewBox 0 0 20 20`，stroke 1.6，fill none，round cap/join）：

| 页面 | 语义 | Path |
| --- | --- | --- |
| 窗口操作 | 窗口框 + 标题栏分隔线 | `M2.5 4.5 H17.5 V15.5 H2.5 Z M2.5 8 H17.5` |
| 鼠标手势 | 轨迹箭头 | `M3 10 H17 M13 5.5 L17.5 10 L13 14.5` |
| 触发与反馈 | 闪电（被触发） | `M11.5 2.5 L5.5 11 H10 L9 17.5 L15 9 H10.5 Z` |
| 应用规则 | **盾牌**（名单类规则） | `M10 2.5 L16 5 V9.5 Q16 14.5 10 17.5 Q4 14.5 4 9.5 V5 Z` |
| 通用 | 滑杆（圆点把手） | `M3.5 7 H16.5 M3.5 13 H16.5 M8 5.7 A1.3 1.3 0 1 0 8 8.3 A1.3 1.3 0 1 0 8 5.7 M13 11.7 A1.3 1.3 0 1 0 13 14.3 A1.3 1.3 0 1 0 13 11.7` |
| 关于 | 闭合圆 + i | `M10 2.5 A7.5 7.5 0 1 0 10 17.5 A7.5 7.5 0 1 0 10 2.5 M10 9 V14 M10 6.2 V6.3` |

**已否决的形状**（勿再使用）：窗口里叠十字线（糊）、同心弧（像雷达）、漏斗（筛选≠规则）、矩形加三道横线（文档≠设置）、圆未闭合（画坏）、列表+勾与线段把手滑杆（16px 下认不出）、分流线（视觉呈 T 形，语义不清）。

设计过程与放大对照见 `https://hermes.fs1m.com:8688/report/altgestures-icons.html`。

## 版本号呈现

- **标题栏不显示版本号**
- 版本号只出现在「关于」页，且**从程序集读取**（`<Version>` 定义在 csproj），不得硬编码在 XAML 里

## 实施

Phase 3 用 **Avalonia**（net8.0）实现。选它而非 WPF 的原因：可在 Linux 构建验证、支持 NativeAOT、未来可跨平台。
