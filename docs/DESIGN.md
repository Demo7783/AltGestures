# 架构设计

## 1. 触发键分配（默认值）

系统里所有鼠标行为由**同一套低级钩子**接收，按修饰键状态分发到两个分支。

| 物理键 | 无修饰键 | 按住 Alt |
| --- | --- | --- |
| 左键 | 放行给系统 | **移动窗口**（拖拽型） |
| 中键 | 可绑手势（默认关） | **缩放窗口**（拖拽型） |
| 右键 | **手势（主触发键）** | 缩放窗口（可改） |
| 侧键 4 (X1) | **手势（备用触发键）** | 可配动作（默认空） |
| 侧键 5 (X2) | **手势（备用触发键）** | 可配动作（默认空） |
| 滚轮 | 可配（滚动非活动窗口） | 切换窗口 / 音量 / 透明度 |

**正交性**：Alt 键状态是唯一分界依据 —— `Alt 按下 → 窗口操作`，`未按下 → 手势`。
两者物理动作相同但语义完全分开，互不抢占。

**侧键的作用**：右键在多数程序里被右键菜单占用，手势必须靠位移阈值区分「点击」与「轨迹」。
侧键没有这个负担，因此把高频手势绑到侧键可获得最干净的手感。四种触发键（右键/中键/侧键 4/侧键 5）
在轨迹绘制中使用**各自独立的颜色**，便于区分。

同一手势轨迹叠加不同的触发键或修饰键，可绑定到不同命令（见 `Gesture` 的 `GestureTriggerButton` + `GestureModifier` 组合）。

## 2. 仲裁状态机

单一状态机，状态在鼠标键**按下瞬间锁定**，中途不切换。

```
IDLE
 ├─ 鼠标键按下(B, 修饰键 M)
 │   ├─ M 含 Alt 且 B 有配置动作
 │   │   ├─ 拖拽型(Move/Resize) → DRAGGING
 │   │   └─ 点击型(Close/Minimize/Center/AlwaysOnTop/Lower) → 立即执行，并吞掉该键 up
 │   └─ B 是手势触发键（且 M 不含 Alt）→ GESTURE_PENDING
 │
 ├─ 鼠标移动
 │   ├─ DRAGGING        → 节流更新窗口位置/尺寸（阈值见下）
 │   ├─ GESTURE_PENDING → 位移超阈值则转 GESTURE_ACTIVE，开始采点并吞事件
 │   └─ IDLE            → 忽略（不监听移动，零开销）
 │
 └─ 鼠标键抬起
     ├─ DRAGGING            → 结束，提交位置；记录 clickTime
     ├─ GESTURE_ACTIVE      → 识别轨迹 → 执行命令；吞掉 up
     ├─ GESTURE_PENDING     → 未超阈值，放行（系统正常弹右键菜单）
     └─ IDLE                → 放行
```

双击判定在**按下时**进行：`now - lastClickTime <= GetDoubleClickTime()` 命中则执行双击动作并吞掉 up
（若不吞，桌面与资源管理器会跟着弹出右键菜单）。

## 3. 性能纪律

钩子回调运行在系统输入链路上，超时（默认 300ms）会被 Windows **静默摘除**。

- 回调内只做：读坐标、写状态位、返回。**禁止**轨迹识别、文件 IO、进程启动、UI 更新。
- 待机态**不监听** `WM_MOUSEMOVE`；进入拖拽/手势模式后才采点。
- 窗口移动按像素阈值节流（对应上游 `MoveRate` / `ResizeRate`），保证更新间隔有上限。
- 目标：常驻内存 < 25 MB，待机 CPU 0%。

## 4. 模块划分

| 项目 | 目标框架 | 职责 | 可编译平台 |
| --- | --- | --- | --- |
| `AltGestures.Core` | net8.0 | 钩子、状态机、手势识别、命令、配置 | 跨平台（Linux 可编译可测） |
| `AltGestures.App` | net8.0 | 界面与托盘 | 跨平台编译，Windows 运行 |
| `AltGestures.Tests` | net8.0 | 单元测试 | 跨平台 |

Core 层**不得**引用任何 UI 框架 —— 这一约束是执行方能自验编译的前提。

## 5. 配置

- 单一 JSON 文件：`%APPDATA%\AltGestures\config.json`
- 改动热重载，不需要重启进程
- 配置结构分三段：`WindowActions`（Alt 分支）、`Gestures`（手势绑定）、`Blacklist`（进程/窗口规则）

## 6. 许可证边界

| 上游 | 许可证 | 使用方式 |
| --- | --- | --- |
| WGestures | GPL-2.0 | 代码可搬（本项目整体 GPL-2.0） |
| AltDrag | GPL-3.0-or-later | **仅参考行为与默认值，代码自主实现** |

两者不兼容（GPL-2.0-only 与 GPL-3.0 无法合并），因此窗口拖拽部分必须基于通用 Win32 API
（`WindowFromPoint` / `GetAncestor` / `GetWindowRect` / `SetWindowPos`）独立实现。
